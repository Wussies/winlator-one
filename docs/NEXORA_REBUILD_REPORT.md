### Что работает неправильно
1. **Сборка debug-типа** — антивирусы и Play Защита считают такие APK подозрительными.
2. **`XServerDisplayActivity` экспортирован**: любое приложение на телефоне может запустить его и передать `boot_exe` (произвольную программу для Wine), а через `DEBUG_INJECT_TAP/KEY` — внедрять нажатия. 🔴 Это реальная уязвимость.
3. Экспортированы `ShortcutBroadcastReceiver` и `DolphinEmulationActivity`; сокет `winlator_vibration` без проверки, кто подключается.
4. Лишние разрешения: `WRITE_SECURE_SETTINGS` (не используется), `REQUEST_INSTALL_PACKAGES` (нужен только отключённому обновлятору), `SYSTEM_ALERT_WINDOW` (пузыри чата Steam), `MANAGE_EXTERNAL_STORAGE` (полный доступ к файлам, противоречит ТЗ).
5. Путь «Linux-контейнер со Steam» скачивает среду из релизов WinNative-Emu и драйвер из личного репозитория — на Этапе 1 я его не перевёл на закреплённые копии.
6. Внутри `wn-libsteamclient` есть диагностическая функция «внедрить тестовый билет владения» — убрать.

## 2. Аудит безопасности (новое по сравнению с Этапом 1)

APK `build5` (SHA-256 в `audit/results/apk-scan/`) проверен на GitHub-раннере, ничего не запускалось.

| Инструмент | Результат |
|---|---|
| **MobSF** | Оценка безопасности **33/100**. Трекеров 0. Среди 154 доменов в коде нет известных вредоносных. Высокие замечания: `debuggable=true`, StrandHogg 2.0 (5 Activity), ECB/CBC в `LinuxSteamLogin` (это формат самого клиента Steam), экспортированные компоненты, сокет без аутентификации |
| **ClamAV** (с проверкой PUA) | 14 271 файл, 3,35 ГиБ: **2 срабатывания** — `PUA.Win.Packer.Embedpe-3` на `kernel32.dll` из Proton 9 (Wine). Это эвристика «PE внутри PE», типичная для встроенных DLL Wine, вирусом не является. Но **именно такие эвристики вызывают предупреждения антивирусов** |
| **APKiD** | «DexGuard» — ложное срабатывание: правило ловит любые пути ассетов, оканчивающиеся на `-`. Реальных упаковщиков нет. Проверки `Build.MANUFACTURER/FINGERPRINT` — профили устройств и библиотеки Google, не антиотладка |
| **Встроенные исполняемые файлы** | Верхний уровень APK: 33 DEX, 60 ELF, 8 PE. Внутри архивов — сотни Windows `.exe/.dll` (Wine, Proton, контейнеры) |
| CodeQL (со сборкой), Semgrep, Gitleaks, OSV, Trivy | Без изменений с Этапа 1 (`SECURITY_AUDIT.md`) |

**Почему Play Защита и антивирус телефона ругаются (наиболее вероятно, в порядке веса):**
1. Отладочная сборка (`debuggable=true`), подпись неизвестного разработчика, нет установок из Play.
2. Набор разрешений, характерный для вредоносных программ: установка APK, системные настройки, наложение поверх экрана, полный доступ к файлам, микрофон.
3. **Сотни Windows-программ внутри APK** (Wine/Proton) и эвристики вроде `Embedpe`.
4. Нативные хуки и `proot`/`ptrace` (`libmain_hook`, `libfile_redirect_hook`, `libproot`), которые выглядят как техники malware.
5. Экран входа в Steam с полем пароля в приложении не от Valve: фишинг аккаунтов Steam — частая категория Android-malware.

Отсутствие срабатываний не доказывает безопасность. Обратное тоже верно: срабатывания здесь — эвристики, а не найденный вирус. Для сравнения: в 2025 году в файлах Winlator был обнаружен **настоящий** вирус Win32/Floxif. ClamAV его знает, в наших файлах его нет.

## 5. Почему такая архитектура

Код **не переписывается с нуля**: Steam-клиент, Wine-окружение и X-сервер — это сотни тысяч строк проверенного кода. Переписывать их означало бы годы работы и новые ошибки. Вместо этого:
- **основа — WinNative**: у него из всех кандидатов меньше всего закрытого кода, есть открытый клиент Steam и законный путь через официальный клиент;
- **из GameNative** переносится только открытый код, когда он лучше (Amazon);
- приложение разбивается на **17 модулей из ТЗ** постепенно: каждый перенос — отдельный коммит с зелёной сборкой. Новые модули (браузер, загрузки, режимы ввода A/D, менеджер безопасности) пишутся как отдельные Gradle-модули с интерфейсами;
- **Windows-компоненты убираются из APK**: Wine/Proton, контейнеры и DirectX-библиотеки скачиваются при первом запуске из релизов NEXORA с проверкой SHA-256. APK становится маленьким, и в нём нет сотен Windows-программ, которые раздражают антивирусы.

## 7. Настоящая интеграция Steam

1. **Вход.** Протокол аутентификации Steam (`IAuthenticationService`) напрямую к серверам Valve, без посредников. Два способа:
   - **QR-код** — если есть второй экран с приложением Steam;
   - **Логин и пароль** — единственный способ на одном телефоне. Пароль шифруется RSA-ключом Valve и уходит только на серверы Steam; он не хранится, не логируется и сразу стирается из памяти. Подтверждение Steam Guard — кнопкой «Подтвердить» в приложении Steam на этом же телефоне или кодом.
   - Хранится только refresh-токен (`EncryptedSharedPreferences`, ключ в Android Keystore). Есть выход, повторный вход, обработка истёкшей сессии. *Это меняет решение Этапа 1 («только QR») — его нельзя использовать с одним телефоном.*
2. **Библиотека.** PICS: только лицензии вашего аккаунта, обложки с CDN Steam, App ID, размер, статус установки и обновления.
3. **Владение.** Серверы Valve выдают ключи депо и коды манифестов **только для купленных игр**, поэтому без владения файлы игры не скачать.
4. **Загрузка.** Депо с CDN Steam по манифестам: прогресс, скорость, пауза/продолжение (докачка по чанкам), отмена, проверка SHA-1 чанков.
5. **Запуск.**
   - Игры без Steamworks и DRM — напрямую в Wine/Proton.
   - Игры со Steamworks/Steam DRM — через **официальный клиент Steam**: arm64-клиент для Linux с CDN Valve (проверка SHA-256 по манифесту Valve) в Linux-среде NEXORA с Proton. Сессия передаётся клиенту локально.
6. **DLC, Steam Cloud, Workshop, ветки, достижения** — в коде есть, статус «Implemented, не проверено» до проверки на устройстве. Достижения работают только при официальном клиенте.

**Честные риски:** официальный клиент Steam в Linux-среде тяжёлый — интерфейс на CEF под эмуляцией, нужны 1–2 ГБ на диске и время на первый запуск. Скорость на OnePlus 13 неизвестна. Valve может изменить протокол — тогда нужно обновить клиент на Rust.

## 8. Ограничения OnePlus 13

| Ограничение | Последствие |
|---|---|
| Adreno 830: Turnip для A8xx остаётся экспериментальным | По умолчанию — системный драйвер Qualcomm через Vortek/обёртку; Turnip только по выбору после теста |
