## 2. Выбор основы

**WinNative (`72d145b`) — с обязательной чисткой** (см. `SECURITY_AUDIT.md`, §6).

Почему не GameNative, хотя функций у него больше: его ключевые части (`libredirect.so` — запуск игр на Android 15+, `libsteambootstrap.so` — вход в «реальный» Steam с вашим токеном) закрыты. Ставить закрытый код, который получает ваш токен Steam и внедряется в каждый процесс игры, противоречит приоритету №1 ТЗ. Без этих библиотек, по признанию самих авторов, GameNative на современных Android практически не запускает игры.

Почему WinNative: функционально близок (Steam, Epic, GOG, локальные игры, контейнеры, редактор управления), но весь специфичный native-код, включая клиент Steam, — **в исходниках**, телеметрии нет, обновлятор проверяет подпись APK, native-код уже выровнен под 16 KB.

**Что переносим дополнительно (только открытый код, после ревью каждого файла):**
- Amazon Games — из GameNative (GPL-3.0 → GPL-3.0 совместимо).
- Vortek — из Winlator (LGPL-2.1, совместимо с GPL-3.0) — важная альтернатива для Adreno 830.

**Лицензия NEXORA станет GPL-3.0** (наследуется от WinNative). Репозиторий должен оставаться открытым, исходники — доступными получателям APK.

| Удалённые каталоги компонентов из личных репозиториев | Изменяемые, без подписи | Каталог компонентов NEXORA: фиксированные версии + SHA-256 в APK, загрузка только с официальных релизов проектов |

## 4. Steam и магазины — что реально возможно

- **Steam:** у Valve нет официального OAuth для сторонних клиентов загрузки. OpenID даёт только SteamID, а загрузка игр требует сессии клиента Steam. Самый безопасный доступный путь — **вход по QR-коду**: вы подтверждаете вход в официальном приложении Steam, пароль в NEXORA не вводится. Токен хранится в Android Keystore. Библиотека, загрузка, обновление, удаление, DLC, Workshop, облачные сохранения уже есть в коде WinNative. **Ограничение:** игры с защитой Steamworks/SteamStub без gbe_fork/Steamless запустятся только при работающем официальном клиенте Steam внутри Wine — тяжелее и пока не проверено на телефоне.
- **Epic / GOG / Amazon:** публичного API для сторонних лаунчеров у них нет. Все открытые лаунчеры (Heroic: Legendary, gogdl, Nile) используют те же неофициальные, но общепринятые методы: вход через **официальную страницу магазина** в WebView/браузере, затем токен. DRM-free игры GOG — без ограничений; Epic — игры с собственной защитой издателя могут не запуститься.

## 6. Ограничения OnePlus 13

1. **Adreno 830:** штатная сборка Turnip из Mesa для A8xx — экспериментальная. Существуют только сборки сообщества («Turnip Gen8»), их надёжность не подтверждена. По умолчанию — **Vortek** (системный драйвер Qualcomm), Turnip — только вручную после тестов.
2. **W^X:** для запуска Wine/Box64 из данных приложения нужен **targetSdk 28**. Android 16 установит такое приложение с предупреждением; Google Play — невозможен, только установка APK. Обход через targetSdk 36 есть только в закрытом коде GameNative — не используем.
3. **Память:** 12/16/24 ГБ LPDDR5X — лимиты для контейнера и кэша шейдеров по объёму ОЗУ.
4. **Нагрев/энергия:** только легальные средства (ограничение FPS, разрешение рендера, профили). Никаких подменных package name и принудительных частот.
5. **OxygenOS:** агрессивная выгрузка фоновых процессов → foreground service + инструкция «Не оптимизировать».
6. **16 KB страницы:** WinNative уже собирает native-код с выравниванием 16 KB.

1. Проверить состояние git: сейчас **чисто**, незакоммиченных изменений нет.
2. Резервная ветка `backup/winlator-one-0.1.0` от текущего `main` (`7673223`).
3. Резервный тег `backup-winlator-one-0.1.0`. Из моей среды теги в ваш репозиторий не пушатся (ошибка 403) — создам его через GitHub Actions.
4. Ветка `nexora/main` от текущего `main`. Коммит 1: удаление старой реализации (история сохраняется). Коммит 2: импорт WinNative `72d145b` с файлом происхождения `PROVENANCE.md`. Коммит 3+: карантинный список.
5. Новый CI: сборка APK, подпись приватным ключом из Secrets, CodeQL **со сборкой**, Gitleaks, OSV-Scanner, Gradle lockfile, Dependabot.
6. Повторный аудит → PR `nexora/main` → `main` **обычным слиянием, без force-push**. Имя репозитория `winlator-one` не меняется.
